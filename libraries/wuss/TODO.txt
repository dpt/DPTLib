Wuss

Ordered by dependency. Each layer builds on the ones above it.
Items marked (blocks: X) are prerequisites for X.


LAYER 0 - BUGS (fix before building on top)

- SDL bug? Random mouse focus issue that stops us receiving initial clicks.


LAYER 1 - CORE PLUMBING (no wuss deps; unblocks everything else)

- Masks: how to get (alpha) masks into the system? Another channel,
  fixed value, or a second bitmap? Decide the model first.
    blocks: Draw bitmap through mask, Masked sprites/bitmaps, furniture tinting
- Named colours?
    blocks: furniture colour selection, desktop palette editor
- 32K/64K colour modes
- Policy? Windows hidden by default (unless a flag is set)
  Wuss lets hidden windows exist in its window stack which complicates the
  code a bit. RISC OS allows hidden (closed) windows by putting them "behind
  the backwindow".
    blocks: window stacks
- Icon type taxonomy


LAYER 2 - TEXT & FONTS (needs UTF-8, font-arch decision)

- Hierarchical fonts (the font-arch decision)
    blocks: bold/italic/large fonts, symbol selection
- 6px desktop font sizing getting built in. Need to be able to specify
  character sizes to the stacker?
    blocks: icon sizing to desktop font
- How to get bold etc. into the system (consistently)? How to select symbols?
- Large fonts for titles, italic font, ...
- Icon size inconsistencies. Need to size to desktop font.


LAYER 3 - SPRITES (needs masks)

- Sprites (with names, with masks, with multiple sprites)
- Masked sprites/bitmaps. Covered by RLE work?
- Sprite scaling
- Import Kare style icons
- App sprites


LAYER 4 - WINDOW FURNITURE & INTERACTION (needs bug layer, text layer)

- Squash-able furniture (shrink below the furniture minimum size)
- Dragging against window edge shuffles window in opposite direction
  (outline-click bug fixed; unblocked)
- Furniture colour selection needs improvements (e.g. losing menu
  readability when palette changed)
- Preferences for window opening positions
- Grid layouts / alignment / something so we can get neat layouts


LAYER 5 - DRAG & TEMPLATES (needs sprites, config-after-the-fact)

- Dragbox concepts (mouse clamping, marching ants)
    blocks: Drag & Drop
- Window and menu templates (text format?)
- Drag & Drop


LAYER 6 - MULTI-TASK (needs stable windows, templates)

- Messaging between tasks
    blocks: Desktop cohort, pop-to-front of running apps
- Pop-to-front of 'running' apps
- Backdrop: register events, or a task that covers it like Pinboard
- Icon bar - a separate task or module?


LAYER 7 - APPS & POLISH (needs most of the above)

- Post-Its app with explanatory text for newbies

- Tiled fills (tile_1)
- Rounded corner windows

- Procedural noise app
- More tasks: TGE/CHQ/...
