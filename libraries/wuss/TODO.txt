LAYER 2 - TEXT & FONTS (needs UTF-8, font-arch decision)

- Hierarchical fonts: let the wuss library itself take a family rather than
  fixed slots, and italic/large selection.
    blocks: bold/italic/large fonts, symbol selection
- Identify and fix places where we've assumed a 6px desktop font size. e.g. use
  of the stacker. Similarly some desktop components are sized around RISC OS
  sizings and not derived from the currently selected desktop font.
- How to get bold etc. into the system (consistently)? How to select symbols?
- Large fonts for titles, italic font, ...
- Wussmoji (needs colour fonts)


LAYER 3 - SPRITES (needs masks)

- Sprites (with names, with masks, with multiple sprites)
- Masked sprites/bitmaps. Covered by RLE work?
- Sprite scaling everywhere
- Icon sprite pools: implement PNG sprite sheets?
- Custom mouse pointers


LAYER 4 - WINDOW FURNITURE & INTERACTION (needs bug layer, text layer)

- Squash-able furniture (shrink below the furniture minimum size)
- Dragging against window edge shuffles window in opposite direction
  (outline-click bug fixed; unblocked)
- Furniture colour selection needs improvements (e.g. losing menu
  readability when palette changed)
- Inside panes: toolbars attached within a parent's content area (e.g. a
  ribbon across the top), shrinking the content rather than sitting outside
- Mouse clamping when the software mouse pointer is enabled
- Window placement:
  - Safe area concept (e.g. where menus overlap the icon bar)
  - Factor out window placement. It's a negotiation between "I need to
    display XxY" and the spare screen area.
  - Decide which windows should open centred etc.
  - Shift-toggle to avoid the icon bar
