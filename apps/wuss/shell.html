Wuss is a sort-of recreation of the RISC OS WindowManager (the Wimp). It's part of my DPTLib, a platform-independent C library shared across my projects. It exercises window creation, z-ordering, mouse routing and dirty-region redraw. It's compiled to WebAssembly via Emscripten's SDL3 port. It has a bunch of mini demo apps built into it.

Like in RISC OS you need a three-button mouse (buttons = Select/Menu/Adjust). Pop open the main menu with the middle mouse button. Drag titlebars to move windows. Click to bring a window to front. F1 redraw all, Shift+F1 fill screen with random pixels (for testing redraw) F2/Shift+F2 zoom window in/out F3 pixel stress test F4 quit
