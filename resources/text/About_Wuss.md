# Welcome to Wuss

**Wuss** is a small portable window manager environment that currently lives inside my code library *DPTLib*. It's something like a fanboy recreation of the RISC OS Window Manager (the _Wimp_ - hence "Wuss") with a few other inspirations thrown in.

Like its inspiration it draws into a plain framebuffer, so it runs anywhere from a desktop to a web browser and even on RISC OS itself.

As with RISC OS, it expects a three-button mouse. From left to right the buttons are called `SELECT`, `MENU` and `ADJUST`. If you're using a trackpad or something use the Configure app to swap MENU and ADJUST around.

## Windows

- Click a window's title bar to bring it to the front
- Drag a **title bar** with `SELECT` to move a window, or with `ADJUST` to move it without raising it
- Scroll to see content that doesn't fit

## Menus

- Click `MENU` over a window to open its menu. Rows with an arrow lead to submenus; ticked rows show the current choice.
